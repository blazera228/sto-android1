СТО — Учёт заказов

Проект Android на Kotlin. Возможности:
- создание заказов;
- имя клиента и автомобиль;
- описание запчастей и работ;
- стоимость запчастей и работ;
- автоматический расчёт общей суммы;
- локальное сохранение заказов на телефоне;
- удаление заказов.

Сборка в GitHub Actions:
1. Загрузите содержимое этой папки в корень репозитория, сохраняя структуру.
2. В Actions запустите workflow Build Android APK.
3. Скачайте артефакт sto-debug-apk и файл app-debug.apk внутри него.

Требования: Android SDK 35, JDK 17, Gradle 8.9.
